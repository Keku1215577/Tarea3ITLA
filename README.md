# Tarea3ITLA

Práctica académica de desarrollo con Blazor y Entity Framework Core orientada a operaciones CRUD sobre productos.

## Componentes identificados

- `Productos.cs`: modelo de producto con identificador, nombre, precio y cantidad.
- `ServiceProduct.cs`: servicio para consultar, crear, actualizar y eliminar productos mediante un contexto de datos.
- `MainLayout.razor`: estructura principal de la interfaz.
- `NavMenu.razor`: navegación de la aplicación.

## Tecnologías

- C#
- Blazor
- Entity Framework Core
- Visual Studio

## Alcance

Este repositorio corresponde a una práctica académica y actualmente contiene una parte del código de la aplicación. No debe presentarse como una aplicación de producción ni como proyecto principal del portafolio hasta completar y documentar su estructura ejecutable.

## Valor para mi perfil

La práctica demuestra fundamentos de:

- Componentes Blazor.
- Servicios para acceso a datos.
- Operaciones CRUD.
- Programación asíncrona en C#.
- Persistencia mediante Entity Framework Core.
